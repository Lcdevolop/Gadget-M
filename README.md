# 🛍️ Gadget M

**Gadget M** — zamonaviy va responsive gadget marketplace web application. Loyiha foydalanuvchilarga smartfonlar, noutbuklar, aksessuarlar va planshetlarni ko‘rish, kategoriyalar bo‘yicha tanlash va mahsulotlar haqida batafsil ma’lumot olish imkonini beradi.

---

## 📌 About The Project

Gadget M loyihasi zamonaviy e-commerce interfeys yaratish va frontend development ko‘nikmalarini amaliyotda qo‘llash maqsadida ishlab chiqilgan.

Loyihada mahsulotlar **API orqali olinadi** va foydalanuvchiga dinamik tarzda ko‘rsatiladi.

Sayt turli ekran o‘lchamlariga moslashtirilgan:

* 🖥️ Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

## 🌐 API

Loyiha mahsulot ma'lumotlarini **DummyJSON API** orqali oladi.

API yordamida quyidagi mahsulot kategoriyalari bilan ishlanadi:

* Smartphones
* Laptops
* Mobile Accessories
* Tablets

Bu orqali mahsulotlar JavaScript yordamida dinamik ravishda sahifaga chiqariladi.
